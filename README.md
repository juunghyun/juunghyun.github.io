## 왜 쓰는가

AI로 일은 빨라졌지만, 내 성장은 AI를 쓰기 시작한 그 시점에 멈춘 것 같았다. 사람이 배우는 속도에는 한계가 있고, 그 속도를 넘어 처리한 일은 내 안에 남지 않는다.

그래서 일하며 실제로 마주한 문제와 해결 과정을 내 언어로 직접 적는다. 기술 소개가 아니라, 겪은 문제를 내 자산으로 만드는 기록이다.
